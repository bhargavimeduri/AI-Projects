4. Phase-by-Phase Blueprint

Phase 1 — Data Collection & Preparation

  • Download 200–500 tiger images from Google Images (different types, angles, lighting)
  • Organise into subfolders by tiger type: orange/, white/, golden/, black/
  • Split: 70% train / 15% val / 15% test
  • Label using Roboflow (beginner-friendly web tool — draw boxes, export YOLO format)
  • Apply preprocessing: CLAHE for dark images, dehazing for fog
  • Data augmentation: flip, rotate, brightness shift — multiply dataset 3–5x
Tools: Google Images, Roboflow (free), Google Drive, Google Colab

Phase 2 — Model 1: Image Triage (Quality Filter)

  • Goal: Reject unusable images before any tiger analysis runs
  • Input: Raw camera trap image
  • Output: One of 4 buckets — Clean / Partial / Unusable / False Positive
  • Algorithm: MobileNetV2 (lightweight, fast, perfect for triage) with Transfer Learning
  • Training: Manually label ~200 images across 4 quality buckets
  • Threshold: If confidence < 0.6 → flag for manual review
Why MobileNetV2: Fast, small, runs on free Colab GPU. Accuracy over speed is not needed at triage stage.

Phase 3 — Model 2: Tiger Detection & Counting

  • Goal: Detect all tigers in a Clean Capture image, draw bounding boxes, count
  • Input: Quality-approved image from Model 1
  • Output: Number of tigers in frame + bounding box coordinates
  • Algorithm: YOLOv8n (nano — fastest, lowest memory, good for Colab free tier)
  • Fine-tune on annotated tiger images (Roboflow export → YOLO format)
  • Filters: Confidence threshold 0.35, box size > 5% of frame
  • Handle multi-tiger frames: loop over all detected boxes
Key metric: mAP@0.5 > 0.7 on validation set before moving to Phase 4

Phase 4 — Model 3: Tiger Type Classifier

  • Goal: For each detected tiger crop — classify color morph AND subspecies
  • Input: Cropped tiger image (output of Model 2 bounding box)
  • Output: Color morph (Orange/White/Golden/Black/Snow White) + Subspecies (Bengal/Sumatran/Siberian/Malayan/S.China)
  • Algorithm: ResNet50 Transfer Learning + custom classification head (2 output layers)
  • Layer 1 head: 5-class color morph softmax
  • Layer 2 head: 5-class subspecies softmax
  • Training data: Label each image with both type and subspecies
Note: Color morph can also be detected with rule-based HSV analysis (no training needed) — use as baseline before training.

Phase 5 — Pipeline Integration & Deployment

  • Connect all 3 models in sequence: Image → Model 1 → Model 2 → Model 3 → Report
  • Output CSV: image name, quality bucket, tiger count, individual ID, color morph, subspecies
  • Simple upload interface: Gradio (free, runs in Colab — just run the cell and get a URL)
  • Forest officials upload folder of images → get summary report automatically
  • No manual intervention required
Deployment tool: Gradio (2 lines of code, runs in browser, no server needed)
